# Splatico landing page

Static HTML and JavaScript with locally compiled Tailwind CSS. The deployed site has no Node runtime, backend, or CDN dependencies.

## Run locally

```sh
npm ci
npm run dev
```

Open http://127.0.0.1:4173. After editing files in `src`, run `npm run build` and refresh the preview. The output is in `dist` and can be served by any static host.

## Replace the placeholders

Edit `SITE_LINKS` at the top of `src/main.js`:

- `steam`: replace the Steam homepage with the game's store URL. Update the Steam links in `src/index.html` too, for visitors without JavaScript. The buy buttons currently lead to the placeholder Steam homepage.
- `youtubeVideoId`: replace the sample Big Buck Bunny video ID with the Splatico trailer ID. Update the iframe title in `main.js`.

The Discord invite, X account, and Fandom URLs come from the game source and existing wiki documents. Screenshots are development and editor captures from the supplied assets. Fonts, logos, character art, favicon, and background are copied from the supplied Splatico folders. Original files are unchanged.

The screenshot gallery supports thumbnails, enlargement, Previous/Next, Left/Right arrow keys, and Escape. The YouTube embed loads only when its play button is clicked. External links include `noopener noreferrer`.

## Feature pages

The map editor, customization, game modes, and chaos landing pages are generated from `scripts/pages.mjs`. They share the main stylesheet and branding. The downloadable press kit is packaged during the build from the original game assets and `src/press-kit.txt`. Press contact: press@splaticogame.com.

Site copy uses American English. The character page is `customization.html`; `customisation.html` remains a compatibility alias. Import screenshots are in `src/assets`. The Blockbench plugin button links to https://github.com/splatico/Splatico-Blockbench-Plugin. The bundled copy in `src/downloads/splatico.js` remains available for compatibility.

The shared header and its page links are generated by `scripts/navigation.mjs`. Desktop dropdowns and the mobile menu use native HTML disclosure controls, with Escape and outside-click dismissal in `src/main.js`.
